========================================
  OCS 网课助手 · AI 答题   一键安装包
========================================

【这包里有什么】
  1-启动答题服务.exe     ← 双击它启动（不用装 Python）
  config.json            ← 接口配置（已预置好，一般不用动）
  OCS网课助手-5.6.6.user.js  ← 装进脚本猫的用户脚本
  题库配置-复制这段.json  ← 粘进 OCS 的题库配置
  选模型-打开网页.url     ← 双击打开选模型网页
  脚本猫插件（备用）      ← 浏览器没装脚本猫时用

========================================
【首次使用 4 步】
========================================

第 1 步：装脚本猫
  浏览器（夸克/Chrome/Edge 都行）装「脚本猫」扩展。
  已在应用商店搜不到，就用本包里的「脚本猫插件（备用）」文件夹：
  浏览器扩展管理 → 开发者模式 → 加载已解压的扩展程序 → 选那个文件夹。

第 2 步：导入 OCS 脚本
  打开脚本猫 → 导入脚本 → 选「OCS网课助手-5.6.6.user.js」。

第 3 步：启动答题服务
  双击「1-启动答题服务.exe」，会弹出一个黑色窗口并自动打开配置网页。
  这个黑窗口别关（关了=停服务）。
  ※ 已预置公网答题通道，什么都不用填就能答题。

第 4 步：OCS 里配置题库
  打开网课页面 → OCS 面板 → 设置/题库配置 → 自定义题库(AnswererWrapper) →
  把「题库配置-复制这段.json」的全部内容粘进去 → 保存。
  答题模式选「AI 搜题 / 自定义题库」。

搞定。之后 OCS 做题会自动搜题、自动作答、自动提交。

========================================
【怎么选模型 / 换成自己的 key】
========================================
双击「选模型-打开网页.url」（或浏览器打开 http://127.0.0.1:38987/）
  · 第 2 区块：点模型名即可切换，下一次答题生效
  · 第 1 区块：想用自己的 key，填 API 地址 + Key + 默认模型 → 保存
    例：DeepSeek 官方  https://api.deepseek.com/v1  + 你的 sk-...  +  deepseek-chat
  · 第 3 区块：可先点「测试」验证答题是否正常

========================================
【常见问题】
========================================
Q：OCS 搜不到答案？
A：确认「1-启动答题服务.exe」的黑窗口开着；确认题库配置已粘进 OCS；
   确认浏览器能打开 http://127.0.0.1:38987/ 。

Q：换模型没生效？
A：切换是下一次答题生效，已发出的请求不会变。

Q：某模型答空/答错？
A：换一个模型；预置的模型已实测可用。

Q：预置通道失效了？
A：在配置网页第 1 区块填自己的 DeepSeek key 即可（platform.deepseek.com 申请）。
