# OCS 题库配置一键获取 —— 题库站对接交接文档

> **协议版本**：`v1`
> **方案**：postMessage 自动回填（零耦合、无共享密钥）
> **适用对象**：题库站开发/运营方、OCS 维护者

## 1. 背景与目标

| | 现状流程 | 对接后流程 |
|---|---|---|
| 步骤 | 打开全局设置 → 题库配置弹窗 → 教程 → 前往题库首页 → 登录 → 获取配置 → 返回粘贴 → 保存 → 刷新 | 题库配置弹窗 → 点「一键获取」→ 登录题库站（如未登录）→ **自动回填并保存** → 刷新 |

题库站**无需**向 OCS 提供 API 密钥、无需注册 client，双方仅约定一个连接页 URL 和一条 postMessage 消息。

## 2. 整体时序

```
用户(网课页面)                        OCS 脚本                         题库站
     │  点击「前往 XX 获取」              │                               │
     ├──────────────────────────────> window.open(connectUrl, 小窗980×720)
     │                                 │ <── 等待消息(轮询窗口关闭+10min超时)
     │  在小窗中登录(如未登录)  ─────────┼────────────────────────────> 连接页
     │                                 │                               登录后:
     │                                 │ <── opener.postMessage({type,version,config})
     │                                 │ 三重校验 + AnswerWrapperParser 解析
     │                                 │ 自动关闭小窗 → 回填弹窗 → 复用手动保存链路 → 提示刷新
```

> 配置读取成功后，OCS 侧弹窗会显示「✅ 题库配置已保存，N 秒后自动关闭小窗…」倒计时，3 秒后自动关闭题库站小窗。

## 3. postMessage 协议规范（v1）

连接页在用户**已登录**后执行：

```js
window.opener?.postMessage(
  {
    type: 'ocs-answerer-config',   // 固定值，协议类型
    version: 1,                    // 协议版本
    config: [ /* AnswererWrapper[] ，见第 4 节 */ ]
  },
  '*'                              // 见下方说明
);
```

**关于 `targetOrigin: '*'`**：opener 是用户的网课页面（超星/智慧树等），域名不可预知，无法枚举，故只能用 `'*'`。安全性由 OCS 侧反向校验保证：

| 校验项 | 说明 |
|---|---|
| `e.source === win` | 消息必须来自本次打开的那个小窗（防页面内 iframe 伪造） |
| `e.origin === connectUrl 的 origin` | 精确匹配 `scheme://host:port`（防其它域名伪造） |
| `type` + `version` | 协议类型与版本匹配，否则忽略 |

## 4. `config` 数据格式（`AnswererWrapper[]`）

```jsonc
[
  {
    "name": "XX题库",                    // 题库名（展示用）
    "url": "https://tiku.example.com/search", // 答题器请求路径
    "homepage": "https://tiku.example.com",    // 题库网址（可选）
    "method": "get",                     // 'get' | 'post'
    "type": "fetch",                     // 'fetch' | 'GM_xmlhttpRequest'
    "data": { "question": "${title}" },  // 请求参数，${title} 为题目占位符
    "headers": { "Authorization": "Bearer xxx" },  // 请求头（鉴权 token 放这里）
    "responseType": "json",
    "handler": "return (res)=>{ ... }"   // 字符串形式的解析函数，res → [[题,答],[题,答]] 或 undefined
  }
]
```

- `config` 也可以直接传 **JSON 字符串** 或 **订阅链接（http 开头）**——OCS 使用标准 `AnswerWrapperParser.from()` 解析，三态兼容。
- 登录态（token）通过 `headers` / `data` / `url` 中的用户级凭证字段传递，题库站请为每个用户生成**独立凭证**，避免全局共享密钥。

## 5. 题库站侧实现清单

1. **提供一个连接页**（如 `https://tiku.example.com/ocs/connect`）：
   - 未登录 → 跳转登录页，登录成功后**回跳到本连接页**（302 或前端路由均可）；
   - ⚠️ **回跳后发起 postMessage 的页面 origin 必须与 connectUrl 的 origin 完全一致**，否则 OCS 会丢弃消息（不要先跳到登录子域名再在子域名发消息）；
   - 已登录 → 直接组装该用户的 `AnswererWrapper[]` 并 `postMessage`，随后可显示“配置已发送，请返回网课页面”。
2. **登录态使用 Cookie 或 URL 参数均可**，OCS 不参与、不存储用户密码。
3. **凭证有效期策略由题库站自定**（建议提供 refresh 或提示用户重新一键获取）。
4. 发送失败兜底：连接页同时保留“手动复制配置”按钮，用户可走 OCS 原有手动流程。

## 6. OCS 侧行为约定（题库站需知晓）

- 弹窗尺寸约 980×720，window.name 为 `ocs_answerer_connect`；
- 等待**整体超时 10 分钟**；小窗被用户关闭则立即失败并提示改用手动配置；
- 配置了 provider 后，设置面板「题库配置」项旁会出现 **「⋯」更多按钮**，点击展开下拉框可选择题库配置获取方式：**官方题库**（默认，即一键获取）/ **自定义题库**（手动配置），选择持久化保存；未配置 provider 时仅显示手动配置界面；
- 选择「官方题库」时点击「题库配置」按钮，弹窗仅包含：获取按钮行 + 状态小字行 + 关闭按钮；选择「自定义题库」时显示原有手动配置界面（教程、填写区、保存按钮）；
- 收到合法消息后 OCS 会：解析校验 → 回填弹窗 → 走既有保存链路（**空配置拦截、去重、数量上限、域名白名单检测**）→ OCS 弹窗显示 **3 秒倒计时提示**后自动关闭题库站小窗 → 提示用户刷新页面；
  - 小窗内部（题库站页面，跨域，OCS 无法注入内容）的「即将关闭」提示由题库站自行展示（见附录参考实现，可选）；
- 校验失败（消息格式非法 / handler 报错）会向用户展示错误并保留手动配置入口，不会写入半成品配置。

## 7. OCS 侧接入开关（仅 1 处）

`packages/scripts/entry.js`（dev/common 版入口同理）：

```js
OCS.setAnswererConfigProvider({
  name: 'XX题库',
  connectUrl: 'https://tiku.example.com/ocs/connect'
});
```

不配置或参数非法时，一键获取入口**不显示**，手动配置功能完全不受影响。

## 8. 验收用例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 已登录用户点击一键获取 | 小窗打开 → 自动回填 → 保存成功 → OCS 弹窗 3 秒倒计时 → 小窗自动关闭 → 提示刷新 |
| 2 | 未登录用户 | 小窗跳登录 → 登录后回跳连接页 → 自动回填 |
| 3 | 其他域名页面伪造消息 | OCS 丢弃，无副作用 |
| 4 | 用户中途关闭小窗 | 弹窗提示“窗口已关闭”，恢复手动入口 |
| 5 | 10 分钟无操作 | 超时提示 |
| 6 | 返回空数组 / 非法 config | 提示配置为空/解析失败，不写入 |
| 7 | 未配置 provider | 弹窗无一键获取入口，仅手动区 |
| 8 | 获取方式切换 | 「⋯」下拉选择官方/自定义题库后，点击「题库配置」分别显示一键获取界面 / 手动配置界面，刷新后选择保持 |

## 附录：连接页参考实现

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>OCS 题库配置连接</title>
</head>
<body>
  <div id="app">
    <p>正在检查登录状态…</p>
  </div>

  <script>
    const CONNECT_PAGE = 'https://tiku.example.com/ocs/connect'; // 本页地址，与 OCS 侧 connectUrl 一致

    async function main() {
      // 1. 检查登录态（题库站自己的接口/cookie）
      const user = await fetch('/api/me', { credentials: 'include' })
        .then((r) => (r.ok ? r.json() : null))
        .catch(() => null);

      if (!user) {
        // 2. 未登录：跳登录页，登录成功后须回跳本页（redirect 参数由题库站自己约定）
        location.href = '/login?redirect=' + encodeURIComponent(CONNECT_PAGE);
        return;
      }

      // 3. 已登录：组装该用户的题库配置（AnswererWrapper[]）
      const config = [
        {
          name: 'XX题库',
          url: 'https://tiku.example.com/api/search',
          homepage: 'https://tiku.example.com',
          method: 'get',
          type: 'fetch',
          data: { question: '${title}' },
          headers: { Authorization: 'Bearer ' + user.token },
          responseType: 'json',
          handler: 'return (res)=>res.code.map(r=>[r.question,r.answer])'
        }
      ];

      // 4. 推送给 OCS（opener 为用户所在网课页面，origin 不可预知，故用 '*'，安全由 OCS 侧校验）
      if (window.opener) {
        window.opener.postMessage(
          { type: 'ocs-answerer-config', version: 1, config },
          '*'
        );
        // OCS 侧保存成功后会在 3 秒倒计时后关闭本窗口；此处自行展示倒计时提示（可选）
        let left = 3;
        const tip = document.getElementById('app');
        const tick = () => {
          tip.innerHTML =
            left > 0
              ? '<p>✅ 配置已发送，' + left + ' 秒后本窗口将自动关闭…</p>' +
                '<p><button onclick="navigator.clipboard.writeText(JSON.stringify(config))">复制配置（兜底手动粘贴）</button></p>'
              : '<p>✅ 配置已发送，请返回网课页面查看。若窗口未自动关闭，可手动关闭。</p>';
          if (left-- > 0) setTimeout(tick, 1000);
        };
        tick();
      } else {
        document.getElementById('app').innerHTML =
          '<p>未检测到 OCS 弹窗来源，请从网课页面的「题库配置」弹窗重新进入。</p>';
      }
    }

    main();
  </script>
</body>
</html>
```
